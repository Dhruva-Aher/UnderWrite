# Devpost: Underwrite

**Headline**: Underwrite: Deterministic Deployment Gates + AI Remediation Advisors for DataHub

**Elevator Pitch**: Target leakage silently destroys ML models. Underwrite solves this by combining deterministic safety with AI-driven developer velocity.

## 🚨 The Problem
**A machine learning model cannot unsee data.** 

If forbidden data (like a future outcome) leaks into your training set, the model is corrupted. Today, this happens silently. Data is renamed across transformations. Pipelines merge. The leak becomes invisible. You deploy a corrupted model, and it fails catastrophically.

You cannot solve this by looking at dashboards. **You solve it by breaking the build.**

## 💡 The Solution: Two-Phase Architecture
Underwrite uses a strict upstream/downstream split to guarantee safety without compromising velocity.

### Phase 1: Deterministic Enforcement (Safety)
When you press deploy, Underwrite deterministically traverses the exact column lineage graph (`UpstreamLineage.fineGrainedLineages`) in DataHub using a cycle-safe Depth-First Search. **The authorization verdict does not depend on an LLM or probabilistic classifier.** If forbidden data reaches the model, it breaks the build. **The deterministic engine is the absolute authority.** Even an APPROVED payload cannot deploy unless its source is an authoritative live DataHub evaluation, preventing malicious bypassing via cached or spoofed results.

### Phase 2: Generative Remediation (Velocity)
When a deployment is blocked, our **AI Remediation Advisor** receives the immutable evidence bundle generated by the deterministic engine. The agent is structurally read-only, using the DataHub Agent Context Kit with `include_mutations=False`, and formats the exact deterministic evidence paths into a prompt. A provider-agnostic LLM synthesizes the investigation into markdown advice on how to fix the pipeline.

**This proves Generative AI can safely coexist with deterministic infrastructure.** The DataHub Agent Context Kit (ACK) is mandatory for this AI remediation to query context, but ACK is never mandatory for the deterministic authorization decision in Phase 1. AI augments human recovery without compromising authorization decisions or relying on unpredictable API interactions.

## 🔗 Why DataHub?
Target leakage rarely manifests at the top-level dataset schema. It hides deep inside multi-hop transformation pipelines where column names change across dbt models and feature stores. DataHub natively tracks **FineGrainedLineage** across heterogeneous tools, enabling our deterministic engine to find leaks that flat-tag checks miss entirely.
